# 🎵 Music Button - Sound Pad

Простое и удобное приложение для воспроизведения звуков через системный аудиовыход. Ваши собеседники в Discord, VK и других программах будут слышать звуки так, как будто они идут с вашего микрофона!

## ✨ Особенности

- **🎯 Простой интерфейс** - интуитивно понятное управление
- **🔊 Поддержка форматов** - MP3, WAV, OGG, FLAC
- **💾 Автосохранение** - ваши звуки сохраняются между запусками
- **🚀 Быстрый запуск** - мгновенное воспроизведение
- **📦 Готовый EXE** - не требует установки Python для конечных пользователей

## 🎯 Как это работает?

**Важно:** Приложение воспроизводит звуки через ваш стандартный системный аудиовыход (динамики/наушники). Чтобы собеседники слышали звуки:

### Способ 1: Stereo Mix (Рекомендуется)
1. Откройте настройки звука Windows
2. Включите "Stereo Mix" (Стерео микшер) в устройствах записи
3. В Discord/VK выберите "Stereo Mix" как устройство ввода вместо микрофона

### Способ 2: Виртуальный аудиокабель (Опционально)
Если нужен более продвинутый контроль, можно установить VB-Audio Virtual Cable

## 📥 Установка и запуск

### Вариант 1: Запуск из исходного кода

1. Установите Python 3.8+ с https://www.python.org/downloads/
2. Откройте командную строку в папке с программой
3. Выполните команду:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```bash
   python main.py
   ```
   Или просто дважды кликните на `run.bat`

### Вариант 2: Создание EXE файла (для распространения)

1. Убедитесь, что выполнены шаги из Варианта 1
2. Запустите `build.bat` двойным кликом
3. Дождитесь завершения сборки
4. Готовый файл будет в папке `dist/MusicButton.exe`

**Теперь вы можете передать этот EXE файл кому угодно - Python не потребуется!**

## 🎮 Использование

1. **Добавить звук**: Нажмите кнопку "➕ Добавить звук" и выберите аудиофайл
2. **Воспроизвести**: Нажмите на кнопку с названием звука для воспроизведения
3. **Удалить звук**: Нажмите "🗑️ Удалить" под нужной кнопкой
4. **Очистить все**: Кнопка "🗑️ Очистить все" удалит все сохраненные звуки

## ⚙️ Настройка звука для Discord/VK

### Для Discord:
1. Откройте Настройки пользователя → Голос и видео
2. В разделе "Устройство ввода" выберите:
   - **Stereo Mix** (если включено в Windows)
   - Или ваш обычный микрофон + включите функцию "Эхо" в Windows
3. Готово!

### Для VK Звонки:
1. Откройте настройки звонка
2. Выберите микрофон → Stereo Mix
3. Готово!

### Как включить Stereo Mix в Windows:
1. Правый клик на значок звука в трее → Звуки
2. Перейдите на вкладку "Запись"
3. Найдите "Stereo Mix" или "Стерео микшер"
4. Правый клик → Включить
5. Правый клик → Использовать по умолчанию

## ❓ Частые вопросы

**Q: Собеседник не слышит звуки!**
A: Убедитесь, что выбрали правильное устройство ввода в Discord/VK (Stereo Mix)

**Q: Можно ли изменить громкость?**
A: Да, используйте системный регулятор громкости Windows

**Q: Сколько звуков можно добавить?**
A: Без ограничений! Но рекомендуется не более 50-100 для удобства

**Q: Где хранятся настройки?**
A: В файле `soundpad_config.json` в папке с программой
