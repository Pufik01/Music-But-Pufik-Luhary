# Music Button - Sound Pad

Простое приложение для создания звуковой панели (sound pad), которое позволяет загружать MP3/WAV файлы и воспроизводить их через выбранное аудиоустройство.

## Возможности

- Загрузка звуков в форматах MP3, WAV, OGG
- Воспроизведение звуков по нажатию кнопки
- Выбор устройства вывода (включая виртуальные аудиокабели)
- Поддержка нескольких звуков одновременно
- Простой и понятный интерфейс

## Установка

### 1. Установите зависимости

```bash
pip install -r requirements.txt
```

Также вам понадобится **FFmpeg** для работы с аудиофайлами:

**Windows:**
- Скачайте с https://ffmpeg.org/download.html
- Добавьте в PATH или положите ffmpeg.exe в папку с проектом

**Linux:**
```bash
sudo apt-get install ffmpeg
```

**macOS:**
```bash
brew install ffmpeg
```

### 2. Для работы с Discord/VK нужен виртуальный аудиокабель

Чтобы собеседник слышал звуки:

**Windows:**
- [VB-Audio Virtual Cable](https://vb-audio.com/Cable/) (бесплатно)
- [Voicemeeter](https://vb-audio.com/Voicemeeter/) (продвинутый микшер)

**macOS:**
- [BlackHole](https://github.com/ExistentialAudio/BlackHole) (бесплатно)

**Linux:**
- PulseAudio/PipeWire уже имеют встроенные возможности виртуальных устройств

### Настройка для Discord/VK:

1. Установите виртуальный аудиокабель
2. Запустите приложение
3. В выпадающем списке выберите ваше виртуальное устройство
4. В Discord/VK в настройках микрофона выберите то же виртуальное устройство как вход

## Использование

```bash
python soundpad.py
```

1. Нажмите "+ Добавить звук (MP3/WAV)"
2. Выберите аудиофайл на компьютере
3. Нажмите на появившуюся кнопку для воспроизведения
4. Выберите нужное устройство вывода из списка

## Как это работает

Приложение использует библиотеку `sounddevice` для прямой передачи аудиоданных в выбранное устройство вывода. Если вы выберете виртуальный аудиокабель, звук будет передаваться в программы (Discord, VK), которые используют этот кабель как источник звука.

## Требования

- Python 3.7+
- Tkinter (обычно идет в комплекте с Python)
- FFmpeg
